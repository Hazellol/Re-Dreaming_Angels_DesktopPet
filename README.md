# 妄想天使桌宠（Re-Dreaming Angels DesktopPet）

基于 Electron 的桌面宠物应用。《绝区零》地下偶像组合「妄想天使」三名角色的源码级 Spine 动画还原，支持桌面互动、AI 角色扮演对话与本地语音合成。

- **当前版本**：1.1.1
- **技术栈**：Electron 44 / Spine 4.2 WebGL / DeepSeek API / GPT-SoVITS（本地 TTS，可选）
- **许可**：MIT（项目代码）；角色素材版权归原权利人所有（详见文末）

## 功能特性

| 模块 | 说明 |
|---|---|
| 角色渲染 | 三名角色同屏，源码级 Spine 渲染：每人 6~8 套动作、全套表情（含淡入版本），走动 / 搬起 / 飞行 / 弹跳均有独立姿态与表情 |
| 桌面互动 | 单击互动（随机台词 + 音效 + 表情，30% 概率触发 AI 即时反应）；双击打开聊天；拖动与甩飞（重力落地 + 边界反弹）；右键菜单（角色专属项与通用项） |
| 角色扮演对话 | 基于 DeepSeek API 的多角色对话：手机面板 / 头顶气泡两种样式；情绪联动（回复中的情绪标签驱动角色动作与表情）；时间感知；历史记录保存、复制与编辑重发 |
| 联网模式 | 调用 DeepSeek Responses API 的 `web_search` 能力（服务端搜索，模型自主决定是否检索），配套独立的联网版人设 |
| 角色互聊 | 空闲时角色相互靠近即触发对话（两人或三人），包含走近、面向对方、话题轮换与记忆注入；触发距离 / 冷却 / 对话轮数可调 |
| 本地语音合成 | 可选功能：接入本地 GPT-SoVITS 服务，将 AI 回复文本按情绪合成为语音播放；模型与运行时按需下载，不随整合包分发 |
| 音频系统 | 互动音效 + BGM 播放器（支持从文件夹导入歌曲）：总音量 × 音效 / BGM 三路独立调节、静音、播放模式切换 |
| 控制面板 | 音量、音乐播放器、角色大小（统一 / 单独）、待机与移动频率、AI 对话配置、互聊设置、语音设置、多显示器设置 |
| 系统集成 | 窗口置顶（可开关）、鼠标穿透（自动切换）、单实例锁、开机自启动、托盘图标、救援快捷键、多显示器支持（主屏 / 副屏 / 跟随角色） |

## 快速开始

### 开发运行

```bat
一键启动妄想天使.vbs        :: 双击即可（首次运行自动安装依赖，需已安装 Node.js）
start-dreaming-angels.cmd   :: 等价命令行入口
```

首次启动后，右键任意角色可打开菜单；双击角色进入聊天。

### 打包分发

```bat
npm run pack:portable      :: 生成 dist/ReDreamingAngels-Portable-x.x.x.exe（单文件，双击即用）
npm run pack:installer     :: 生成 dist/ReDreamingAngels-Setup-x.x.x.exe（NSIS 安装程序）
```

> 打包产物使用 ASCII 文件名：部分平台（GitHub Releases、镜像站、下载器）对中文附件名支持不佳。
> 程序内的产品名、快捷方式名仍为「妄想天使桌宠」。

- 打包内容：`main.js` / `preload.js` / `src/` / `assets/`，并合并为 asar
- 打包版本的运行数据写入 `%APPDATA%\ReDreamingAngels\`（不写入安装目录）
- 首次打包需联网下载构建组件（winCodeSign、NSIS），缓存于 `%LOCALAPPDATA%\electron-builder\Cache`

## AI 对话配置

1. 右键角色 →「对话配置」，打开控制台
2. 填写 **API Key**（DeepSeek 开放平台），选择模型（推荐 `deepseek-v4-flash`）
3. 点击「连接测试」，成功后状态标记为已连通（互动时的 AI 反应依赖此状态）
4. 点击「保存配置」，配置即时生效
5. 可调项：温度、回复字数上限、上下文轮数、聊天样式（面板 / 气泡）、联网模式、是否保存历史对话、开机自启动

## 本地语音合成（TTS）

TTS 为**可选功能**，默认关闭。模型与推理运行时**不包含在整合包内**，由用户在控制台中按需下载（每次约 5.45 GB，分 6 个分卷）。

### 组成部分

| 包 | 内容 | 体积 |
|---|---|---|
| 推理环境包 | 精简版 GPT-SoVITS v2ProPlus 运行时（Python + 依赖 + 基础模型） | 约 5.45 GB（6 分卷） |
| 角色语音包 | 单角色的 GPT / SoVITS 权重 + 情绪参考音频 + 情绪映射 | 每角色约 300 MB |

### 使用流程

1. 控制台 →「设置」→「语音（TTS）」
2. 选择**下载源**：GitHub 官方 / ghproxy / ghfast / moeyy / llkk / 自定义加速前缀（内置仓库地址，无需手动填写）
3. 点击**「一键下载推理环境」**：自动依次下载分卷、解压、探测运行时并写入配置（已安装时自动跳过）
4. 按需下载**角色语音包**（爱芮 / 千夏 / 南宫羽），已安装的角色会标记为已就绪
5. 勾选**「启用语音」**与**「聊天回复朗读」**，点击「保存并应用」
6. 点击**「启动服务」**（首次加载模型约 1~3 分钟），状态变为运行中后即可使用

### 情绪映射

AI 回复中的情绪标签（`<mood:...>`）会驱动语音的情绪参考选择：

- 支持情绪：`neutral` / `happy` / `sad` / `angry` / `shy` / `think` / `tired` / `proud`
- 每种情绪对应一组参考音频（来自角色语音包中的 `emotions.json`），合成时随机选取一条，使同一情绪下的语气更自然
- 未配置的情绪自动回落到 `neutral`

语音包由 `tools/build_voicepack.mjs` 从训练标注文件（格式 `音频|情绪标签|台词文本`）自动生成，无需手工标注。

### 数据与配置

所有 TTS 数据存放于项目目录下的 `tts/`：

```
tts/
├─ runtime/          推理运行时（环境包解压位置）
├─ voices/           角色语音包（可选，也兼容读取项目根目录的 tts_out/）
├─ cache/            合成音频缓存
├─ logs/             app.log（应用日志）与 server.log（服务日志）
└─ tts_config.json   配置（服务地址、设备、下载源、朗读范围等）
```

> 打包版本（安装目录只读）会自动回退到 `%APPDATA%` 存放。

### 相关配置项

| 配置项 | 说明 | 默认 |
|---|---|---|
| 推理设备 | GPU（快） / CPU（省显存） | GPU |
| 空闲卸载 | 无请求后自动停止服务以释放显存的等待秒数 | 300 |
| 聊天回复朗读 | AI 回复是否自动转语音 | 开启 |
| 待机台词朗读 | 待机气泡台词是否朗读（较频繁） | 关闭 |
| 互聊朗读 | 角色互聊内容是否朗读 | 关闭 |
| 按角色分目录保存 | 合成音频按角色分目录存放，文件名含情绪与台词片段 | 关闭 |

### 常见问题

- **服务启动失败或合成报错**：打开控制台「后台日志」查看详细过程，日志同时写入 `tts/logs/app.log`
- **语音音色与训练时不一致**：确认推理配置为 v2ProPlus（安装程序会自动写入 `GPT_SoVITS/configs/tts_infer.yaml` 的 `custom` 段），且请求已携带角色权重（默认自动）
- **括号内的动作描述被朗读**：已自动过滤 `（）()【】[]* *` 中的舞台指示，仅朗读台词
- **下载缓慢**：切换下载源（镜像站）或改用其他网络环境

## 操作说明

| 操作 | 方式 |
|---|---|
| 互动 | 单击角色 |
| 聊天 | 双击角色，或右键 → 聊天 |
| 拖动 / 甩飞 | 按住拖动；快速甩动后松手触发重力落地与边界反弹 |
| 触发互聊 | 右键角色 → 互聊 →「找 XX 聊天」/「三人一起聊天」 |
| 调整参数 | 右键 → 各设置面板（音量 / 频率 / 大小 / 播放器 / 互聊 / 对话配置） |
| 添加 BGM | 播放器面板 →「添加歌曲」（导入文件对话框），或放入 `assets/bgm/` 后重启 |
| 找回窗口 | 鼠标移到角色上（自动置顶）、点击托盘图标，或按救援快捷键（默认 `Ctrl+Alt+Z`，被占用时自动降级，实际键位显示在右键菜单底部） |
| 隐藏角色 | 拖出屏幕外，或在大小面板中关闭该角色 |
| 多显示器 | 控制台 →「设置」→「多显示器」：主显示器 / 副显示器 / 跟随角色 |

## 开发与调试

设置环境变量后启动（PowerShell 示例：`$env:QX_CHAT='1'; npm start`）：

| 变量 | 作用 |
|---|---|
| `QX_CHAT=1` | 自动演示聊天流程（面板样式） |
| `QX_CHAT_BUBBLE=1` | 气泡样式演示 |
| `QX_CHAT_SEND2=1` | 自动发送第二条消息（4200ms 后） |
| `QX_CHAT_SWITCH=1` | 聊天样式切换演示（面板 ↔ 气泡） |
| `QX_AI_MOCK=1` | 本地模拟回复（不消耗 API 配额） |
| `QX_WEBTEST=1` | 联网搜索功能测试 |
| `QX_CHATTEST=1` | 强制触发角色互聊 |
| `QX_EDITTEST=1` | 编辑重发流程演练 |
| `QX_BUBBLETEST=top/left/right/topright` | 气泡边缘防出屏测试 |
| `QX_CTX=1` | 右键菜单截图 |
| `QX_GRAVITY=1` | 强制开启重力模式 |
| `QX_SCALES='{"all":65}'` | 角色大小注入（JSON） |
| `QX_AUDIO` / `QX_FREQ` / `QX_CHATTER` | 配置注入（环境变量优先于本地记忆） |
| `QX_BG=black` / `QX_NOCLIP=1` / `QX_NOALPHA=1` | 渲染调试（黑底 / 禁用裁剪 / 禁用预乘） |
| `--screenshot <ms> "hud=1"` | 启动后指定毫秒截图，并在左上角显示渲染状态 HUD |

TTS 相关调试变量：

| 变量 | 作用 |
|---|---|
| `QX_TTS_ENABLED=1` | 强制启用语音 |
| `QX_TTS_PORT` / `QX_TTS_HOST` | 指定服务地址端口 |
| `QX_TTS_DEVICE=cuda\|cpu` | 推理设备 |
| `QX_TTS_VOICES=<目录>` | 指定语音包根目录 |
| `QX_TTS_BYROLE=1` | 按角色分目录保存合成音频 |
| `QX_TTS_TEST='角色\|文本\|情绪'` | 启动后自动合成一句（验证链路） |
| `QX_TTS_UPDATE_TEST=1` | 启动后自动检测更新接口 |

其他调试开关：`QX_POLLLOG`、`QX_ANIMLOG`、`QX_HUD`、`QX_NOPASS`、`QX_ALWAYSPASS`、`QX_SCREENMODE`、`QX_MSLOG` 等，详见 `IMPLEMENTATION_NOTES.md`。
