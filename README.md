# 妄想天使桌宠（Re-Dreaming Angels DesktopPet）

> 《绝区零》地下偶像「妄想天使」三小只 —— **爱芮 / 千夏 / 南宫羽** —— 的桌面宠物。
> 源码级还原三套 Spine 角色（动作+表情全套+走路），会待机卖萌、陪聊、联网搜索、互相聊天。
>
> 📖 文档三件套：本文件（用户手册） · `PROJECT_MASTER_DOC.md`（项目主档/开发者速查） · `IMPLEMENTATION_NOTES.md`（技术手册/坑总集）

---

## ✨ 功能一览

| 分类 | 功能 |
|---|---|
| 🐟 角色 | 三小只同屏（爱芮 粉 / 千夏 绿 / 南宫羽 黑），源码级 Spine 渲染：动作 6~8 套 + 全套表情（含淡入版），走动/搬起/飞行/弹跳各有专属姿态表情 |
| 🖱 互动 | 单击捏捏（随机台词+音效+表情，**30% 触发 AI 即时反应**）；双击打开聊天；拖动/甩飞（重力落地+壁弹）；右键菜单（角色专属项+通用项） |
| 💬 聊天 | 与任意一只 DeepSeek 角色扮演对话：**手机面板** / **头顶气泡** 两种样式；情绪联动（强烈情绪/反差/被逗/被夸 → 角色切换对应动作表情）；时间感知；历史保存（可复制/编辑重发） |
| 🕸 联网模式 | 官方 DeepSeek Responses API `web_search`（服务端搜索，**模型自主决定何时搜**）+ 独立"联网版人设"（被问到人设外信息会主动搜索，仍以角色口吻回答） |
| 👭 小偶像互聊 | 三小只空闲时**靠近即聊**（两人/三人），先走近、面向对方再聊；60% 概率换新话题；台词注入各自记忆（以后真能聊起"上次的事"）；冷却/距离/轮数可调 |
| 🔊 音频 | 捏捏/菜单音效 + BGM 播放器（assets/bgm 拖入即收录）：总音量×音效/BGM 三路分离、静音、播放模式 |
| 🎛 面板 | 音量 / 音乐播放器 / 大小（统一+单独）/ 三小只待机频率（对话频率+走动间隔+**竖直移动**）/ AI 对话配置（控制台）/ 互聊设置 |
| 🧰 系统 | 置顶、鼠标穿透（自动切换）、单实例锁、窗口不隐藏、锁定模式、退出桌宠 |

## 🚀 快速开始

```bat
一键启动妄想天使.vbs        # 或 start-dreaming-angels.cmd（开发运行）
```

1. 双击启动脚本（首次运行即安装依赖；需已安装 Node.js）
2. 欢迎她入住你的桌面 🎉
3. 右键某只 →「💬 聊天…」或**双击她**，体验角色扮演对话（首次需在控制台填 API Key）

### 🤖 AI 对话配置

1. 右键 →「🔧 对话配置」（控制台）
2. 填写 **API Key**（DeepSeek 开放平台），选模型（`deepseek-v4-flash` 推荐 / `deepseek-v4-pro`）
3. 点「⚡ 连接测试」（成功后即标记"连通"，捏捏 AI 反应才会开启）
4. 点「💾 保存配置」（立即热更新）
5. 常用项：温度（越活泼越高）、回复字数上限、上下文轮数、聊天样式（面板/气泡）、**联网模式**、保存历史对话

## 📖 玩法小抄

- **捏一捏**：单击角色
- **聊天**：双击角色 / 右键→聊天
- **搬起她**：按住拖动；**甩飞**：快甩后松手（重力模式会旋转落地+壁弹）
- **叫她找朋友聊**：右键某只 → 互聊板块「找XX聊天」/「👭 三个人一起聊天」（她会先走过去再聊）
- **调参数**：右键 → 互聊 ⚙设置（靠近距离/冷却/轮数）；频率面板（待机频率/竖直移动）；音量面板（总/音效/BGM 三路）
- **加 BGM**：把 mp3 丢进 `assets/bgm/`，重启后出现在播放器列表
- **隐藏某只**：拖到屏幕外 / 菜单"调整XX大小"面板里可休息

## 🛠 调试模式（开发人员）

设置环境变量后启动（如 PowerShell：`$env:QX_CHAT='1'; npm start`）：

| 变量 | 作用 |
|---|---|
| `QX_CHAT=1` | 自动开场演示（手机面板样式聊天） |
| `QX_CHAT_BUBBLE=1` | 气泡聊天样式演示 |
| `QX_CHAT_SEND2=1` | 自动发送第二条消息（4200ms） |
| `QX_CHAT_SWITCH=1` | 聊天样式切换（面板↔气泡） |
| `QX_AI_MOCK=1` | 本地模拟回复（不消耗 API） |
| `QX_WEBTEST=1` | 真实联网搜索测试（千夏"出道曲"） |
| `QX_CHATTEST=1` | 强制触发互聊（千夏×南宫，真实 API） |
| `QX_EDITTEST=1` | 编辑重发自动演练 |
| `QX_BUBBLETEST=top/left/right/topright` | 气泡防出屏边缘测试 |
| `QX_CTX=1` | 右键菜单截图 |
| `QX_GRAVITY=1` | 重力模式开启 |
| `QX_SCALES='{"all":65}'` | 角色大小（json） |
| `QX_AUDIO='{...}'` / `QX_FREQ='{...}'` / `QX_CHATTER='{...}'` | 配置注入（env 优先于本地记忆） |
| `QX_BG=black` / `QX_NOCLIP=1` / `QX_NOALPHA=1` | 渲染器调试（黑底隔离/禁用裁剪/禁用预乘） |
| `--screenshot <ms> "hud=1"` | 启动后指定毫秒截图 + 左上角 HUD（角色姿势/动画状态） |

## ❓ 常见问题

- **聊天没反应 / 提示"尚未配置 API Key"** → 控制台填 Key → 连接测试 → 保存
- **联网搜索好慢** → 搜索 5~15s 属正常（服务端搜索）；在意速度可关联网模式
- **旧聊天记录里出现过"提示配置 API Key"的文本** → 那是早期调试模拟回复，正式请求不会产生（可在控制台清空历史）
- **互聊半天不触发** → 把三只拖近（≤设置距离），或右键 →「找XX聊天」指定触发；检查频率/冷却参数
- **空间占 300MB+** → 是 `node_modules` 里的 Electron 运行时（正常），项目本体仅 ~20MB
